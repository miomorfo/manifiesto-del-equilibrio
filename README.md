# Manifiesto del equilibrio

Una filosofía de vida sin dios, en la que el ser humano ocupa el último lugar frente a las demás criaturas y tiene una deuda con ellas.

**[Leer el manifiesto](https://miomorfo.github.io/manifiesto-del-equilibrio/)**

Versión 0.3, noviembre de 2026. El texto, con sus fuentes, está en [`index.html`](index.html), y el historial de commits guarda cada versión.
